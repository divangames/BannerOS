# BannerOS Constitution

## 1. Product over technology

Решения оцениваются по тому, сколько времени они возвращают пользователю при создании реальных баннеров.

## 2. Portable First

Проект должен переноситься между компьютерами и окружениями без ручной правки абсолютных путей.

## 3. Replaceable integrations

Photoshop, AI-провайдеры, файловые хранилища и экспортные форматы подключаются через интерфейсы и адаптеры.

## 4. Deterministic core

Одинаковые входные данные, профиль и версия движка должны давать воспроизводимый результат.

## 5. Working increments

Каждый спринт заканчивается проверяемой версией, которую можно применить к рабочей задаче.
