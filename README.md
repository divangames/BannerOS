# BannerOS

BannerOS — переносимая платформа для подготовки рекламных баннеров из исходных материалов.

## Цель MVP

Пользователь загружает фотографии товара, выбирает профиль (`HASL` или `OUTMAX`), описывает идею и получает полный комплект баннеров быстрее ручной сборки.

## Репозиторий

- `apps/desktop` — desktop-приложение Tauri + React.
- `apps/api` — API на FastAPI.
- `apps/photoshop-plugin` — адаптер Photoshop UXP.
- `packages/*` — переносимые доменные модули.
- `docs` — продуктовые и архитектурные документы.

## Принципы

1. Portable First: проект и ассеты не должны зависеть от конкретного диска или приложения.
2. Все можно заменить: интеграции подключаются через адаптеры.
3. Каждый спринт заканчивается рабочим результатом.
4. Доменные правила живут в пакетах, а не в UI.

## Старт разработки

Требования: Node.js 20+, pnpm 9+, Python 3.11+.

```bash
pnpm install
pnpm dev:api
pnpm dev:desktop
```

На первом этапе команды запускают минимальные каркасы; реализация Export Engine добавляется в Sprint 1.
